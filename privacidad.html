Política de privacidad

Última actualización: 13 de septiembre de 2026

Esta política describe cómo MoobaWorks, la herramienta interna de automatización de Mooba Works para la gestión de proyectos, usa los datos de la cuenta de Google que la autoriza. MoobaWorks no es una aplicación pública: no tiene registro de usuarios y opera sobre una sola cuenta de Google, autorizada por su propietaria.

1. Datos que solicita MoobaWorks

Al conectarse con la cuenta de Google, MoobaWorks solicita permiso para:

  • Google Drive: crear, guardar y consultar los archivos de cada proyecto.
  • Gmail: enviar correos de aviso cuando termina cada etapa de un proyecto.

MoobaWorks no solicita datos personales adicionales ni recopila información de otras personas.

2. Cómo se usan los datos

Los datos se usan únicamente dentro del flujo de trabajo de MoobaWorks: para guardar y recuperar los archivos de proyecto en Drive y para enviar los avisos de avance por Gmail. El acceso a Gmail se usa solo para enviar esos avisos.

Los datos obtenidos de las API de Google:

  • nunca se venden;
  • nunca se comparten con terceros para fines ajenos al flujo de trabajo;
  • nunca se usan con fines publicitarios.

El uso y la transferencia de información recibida de las API de Google se ajustan a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

3. Quién tiene acceso

Solo la cuenta de Google de la propietaria, que autorizó a MoobaWorks. No existen usuarios externos ni cuentas de terceros con acceso a la herramienta o a sus datos.

4. Dónde se almacenan

Los archivos de cada proyecto se almacenan en el Google Drive de la propietaria. MoobaWorks no mantiene una copia externa de esos archivos.

5. Cómo revocar el acceso

La propietaria puede retirar en cualquier momento el permiso concedido a MoobaWorks desde la configuración de su cuenta de Google, en myaccount.google.com/permissions. Al hacerlo, MoobaWorks deja de poder acceder a Drive y a Gmail. Los archivos que ya estén en Drive permanecen ahí bajo el control de la propietaria.

6. Cambios a esta política

Si esta política cambia, la versión actualizada se publicará en esta misma página con una nueva fecha de actualización.

7. Contacto
